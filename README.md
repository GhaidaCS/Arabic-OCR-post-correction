Input Format:
The input will be an image containing Arabic text along with the text generated by an OCR system.
The OCR text may have different types of errors, such as incorrect characters, missing or extra characters, or incorrect spacing between words.
The original image is important because it can be used as a reference when the OCR output is unclear or incorrect.

Output Format:
The output should be the corrected Arabic text based on both the image and the OCR result.
The model should only correct errors in the OCR output and should not add new information or explanations.
The output should be a clean text sequence that represents what is actually written in the image.

What Does “Correct” Mean?
For this project, I would focus mainly on word-level and character-level accuracy rather than diacritics.
The goal is to fix actual OCR errors, such as confusing similar Arabic characters, missing letters, extra letters, or incorrect word boundaries.
Diacritics can be preserved when they are available, but they should not be required for the text to be considered correct.

Tesseract baseline: CER = 4.82%, WER = 12.40% on 10 manually corrected Arabic OCR samples.
Zero-Shot Qwen: CER = 7.75%, WER = 25.84% on 10 manually corrected Arabic OCR samples.
